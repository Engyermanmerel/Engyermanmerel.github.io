## 📌 Vision & Strategy
This is not just a personal website; it is a **scalable modular system** designed to document and showcase high-level engineering projects. The architecture has evolved from a static monolithic model to a dynamic data-driven engine, reflecting my professional transition from Electromechanical Engineering to Systems Architecture.



---

## 🛠 Tech Stack & Architecture

### **Current Version (v2.2): The Modular Engine**
In the current iteration, the focus is on **Separation of Concerns** and data management efficiency:
* **Core:** HTML5, CSS3 (Custom Properties & Grid).
* **Logic:** JavaScript (ES6+).
* **Dynamic Injection:** Implementation of **Fetch API** to consume JSON data dictionaries, making the UI independent of the content.
* **UX/UI:** Minimalist design inspired by **Tesla’s** visual language, prioritizing technical hierarchy and readability.

### **Evolution Roadmap**
1.  **v1.0 (Legacy):** Static monolithic structure (Basic HTML/CSS/JS).
2.  **v2.2 (Current):** Modular architecture, dynamic component injection, and performance optimization.
3.  **v3.0 (Planned):** Migration to **React.js** for complex state management and real-time **Digital Twin** visualization integration.

---

## 🏗 Key Features

- **Asynchronous Data Loading:** Projects are loaded dynamically via JS dictionaries, reducing the initial DOM size and improving Time to Interactive (TTI).
- **Systems Engineering Approach:** The portfolio is treated as a "System of Systems," where the UI, Data, and Logic are decoupled subsystems.
- **Responsive Engineering:** Adaptive layout designed under engineering principles: functional, precise, and efficient across all devices.
- **Deep-Dive Modals:** Each project includes a technical breakdown (Abstract, Modeling, Results) ensuring technical depth is never sacrificed for aesthetics.

## 📊 Performance & Decision Analytics

As an engineer, every technical decision is backed by data. The migration from v1.0 to v2.2 was justified through scalability analysis:

| Metric | Monolithic (v1.0) | Modular (v2.2) | Target (v3.0 - React) |
| :--- | :--- | :--- | :--- |
| **Initial Load** | 0.4s | 0.6s | 1.1s |
| **Scalability** | Low | Medium-High | Infinite |
| **Data Decoupling** | 0% | 100% | 100% |
| **Logic Complexity** | Linear | Controlled | State-Driven |

## 🚀 How to Explore the Code

2.  **Modular Logic:** The `app.js` file contains the injection engine logic and modal state management.
